## 小狐狸申请叙事的第一版方向

《夜神社咖啡》不只作为一款京都题材的动作经营游戏提交，而作为“日常劳动与夜间祓除之间的节奏切换，如何让玩家形成对场所、角色与责任的情感连接”的创作研究原型。第一章 Vertical Slice 用于验证操作、状态转换、风险回报、Boss 学习曲线及氛围表达；后续研究通过玩家测试比较不同昼夜节奏、任务反馈和失败恢复方式对体验的影响。
